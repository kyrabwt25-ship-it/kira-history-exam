# KIRA AI — النسخة 2 (كاملة)

حسابات • شات • صور • 4 باقات • **لوحة مطور** • **اشتراكات ودفع** • **ربط المناهج (بحث نصي)**

## التشغيل
1. Supabase: SQL Editor ← شغّل `schema.sql` ثم `schema2.sql` ثم `schema3.sql` (بهذا الترتيب).
   فعّل Authentication ← Providers ← Email ← **Confirm email** (مهم لأمان حساب المطوّر).
   (لو شغّلت schema.sql سابقًا، شغّل schema2.sql فقط.)
2. اصنع نفسك مديرًا بعد أول تسجيل دخول:
   `update profiles set role='admin' where email='you@example.com';`
3. انسخ `.env.example` إلى `.env` واملأه (مفاتيح Anthropic وSupabase، وإعدادات الدفع).
4. `pip install -r requirements.txt` ثم `uvicorn main:app --reload`
5. التطبيق: http://localhost:8000 — لوحة المطور: http://localhost:8000/admin.html

## لوحة المطور
نظرة عامة • المستخدمون (ترقية/حظر) • الباقات (النموذج والحدود والأسعار والتعليمات) •
الاشتراكات (تأكيد دفع يدوي) • المناهج (رفع PDF/TXT) • الإعدادات (شخصية KIRA + وضع الصيانة).

## الدفع
- **يدوي (يشتغل من اليوم):** الطالب يضغط ترقية ← يحصل على رقم طلب وتعليمات (MANUAL_PAY_NOTE) ← يحوّل (إنستاباي/فودافون كاش) ← تؤكد من لوحة المطور ← يتفعّل.
- **بوابة (Paymob/Fawry/Kashier):** ضع رابط الدفع في PAYMENT_URL_TEMPLATE، واضبط في بوابتك Webhook إلى
  `https://موقعك/api/webhook/payment` بتوقيع HMAC-SHA256 في الهيدر `X-Signature` (السر = PAYMENT_WEBHOOK_SECRET).
  شكل الإشعار الافتراضي `{"payment_id":"...","status":"paid"}` — عدّله في دالة `payment_hook` في main.py ليطابق بوابتك.
- التجديد يمدّد الاشتراك من تاريخ انتهائه، والانتهاء يرجع الحساب للمجانية تلقائيًا.

## المناهج
ارفع كتبًا من لوحة المطور (حدّد المرحلة والمادة). عند السؤال يبحث النظام في المقاطع المطابقة ويضيفها للنموذج
ويذكر المصدر في آخر الرد. ملفات PDF الممسوحة كصور لا يُستخرج منها نص (تحتاج OCR).
البحث نصي (Postgres FTS) بدون خدمات إضافية؛ يمكن ترقيته لاحقًا إلى بحث دلالي بالمتجهات.

## النسخة 4
- **المطوّر** (الحساب ذو role=admin، أي بريدك المؤكَّد) يستخدم دائمًا أعلى نموذج (`TOP_MODEL`) مع ردود أطول، وإن لم يتوفر لحسابك يتحوّل تلقائيًا إلى `FALLBACK_MODEL`.
- النموذج يعرف أنك المطوّر **من النظام وليس من كلام المحادثة**، فلا يستطيع أحد ادّعاء ذلك.
- تعليمات «الحل الكامل والتحقق» (`CORE` في main.py) تُضاف لكل المحادثات.
- لرفع باقة Ultra أيضًا لأعلى نموذج: غيّر عمود `model` في جدول `plans` (انتبه للتكلفة).
